# Pocket Snake

A classic Snake game in plain HTML, CSS and JavaScript, styled like a retro LCD handheld. No build step and no dependencies: everything is in `index.html`.

## Play

Open `index.html` in any browser, or enable GitHub Pages for this repository to play it online.

## Controls

| Action | Keyboard | Phone |
| --- | --- | --- |
| Steer | Arrow keys or W A S D | Swipe on the screen or use the pad |
| Start / pause | Space or P | Red START button |
| Restart | R | START after game over |

## Features

- Speed increases every 5 food, and points scale with the level
- Blinking bonus food with a countdown bar, worth 50 × level
- "Wrap walls" mode to pass through the edges
- High score, wrap and sound settings saved in the browser
- Optional chiptune sound effects
- Auto-pause when you switch tabs
